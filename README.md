# Alvin Malik Ibrahim — Portfolio

Vue 3 + Vite + Tailwind portfolio with build-time rendered home and case-study pages.

## Development

Use Node.js 20 or newer.

```sh
npm ci
npm run dev
```

## Production and tests

```sh
npm run build
npm test
npm run preview
```

The build creates client assets, a temporary Vue server-rendering bundle, and static HTML for every project in src/data/projects.js. Publish only dist. No Node server is needed in production. vercel.json retains static deployment with trailing-slash case URLs.

Development uses Vue client rendering. Production HTML, SEO metadata, sitemap, robots and the 404 artifact are generated by scripts/prerender.mjs; use the production build when validating them.

## Content and assets

- Profile, contact, CV and testimonials: src/site.config.js.
- Case studies: src/data/projects.js.
- Preserve factual evidence and permissions when adding testimonials, screenshots or metrics.
- Run npm run assets to regenerate WebP images and the social preview from existing PNG sources. Generated assets are committed.
- The English CV is generated with Python + ReportLab using scripts/create-cv.py. Regeneration is optional for normal builds. Render and visually check a regenerated PDF.
- The original CV stays in the repository but is intentionally omitted from dist because it contains additional personal details.

See docs/portfolio-audit-plan.md for the initial mapping and docs/portfolio-audit-results.md for verification, limitations and remaining recommendations.
